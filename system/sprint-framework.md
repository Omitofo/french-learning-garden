# Sprint Framework

A sprint is the basic unit of learning.

## Required elements

- Circumstance (real-life situation)
- Communicative objective / Seed
- One core phrase
- Meaning
- Breakdown (vocabulary, structure, necessary grammar, pronunciation if relevant)
- Context of use
- A few useful variations
- Practice path (observe → produce)
- Proof of capability
- Before → After
- Status (new / growing / usable)

## Size rule

Keep it small. One clear communicative gain.

## Definition of done

A sprint is done when the capability is **usable**, not perfect.
