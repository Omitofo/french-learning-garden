# PROJECT SPEC — French Learning Garden

This is the source of truth for the project.

## Summary of the system

French Learning Garden is an adaptive learning system based on small sprints. Each sprint uses one useful phrase inside a real circumstance to plant or strengthen a seed, extracts only the necessary knowledge from it, and ends by demonstrating a new communicative capability. The repository records how that capability grows, detects weaknesses, and decides what to water next. There is no obligatory calendar and no goal of completing a syllabus: the objective is to continuously increase what the user can communicate, understand, interact with, and repair in French.

(The rest of the project specification follows the same principles defined in `system/`.)
