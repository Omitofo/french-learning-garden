# S001 — Basic Request

## Seed

basic-request

## Circumstance

You are in a shop, café, or any place where you need to get something. You want to ask for an object in the simplest possible way.

## Communicative objective

Be able to ask for an object using a short, natural, reusable structure.

## Core phrase

Celui-ci, s'il vous plaît.

## Meaning

This one, please. / I’ll take this one.

## Breakdown

### Vocabulary

- Celui-ci — this one (masculine, near me)
- Celle-ci — this one (feminine, near me)
- Ça — this / that (neutral, very common)
- S'il vous plaît — please (formal/polite)

### Structure

[Object / Demonstrative] + s'il vous plaît

### Grammar / pattern

In shops and cafés, pointing + a short demonstrative + "s'il vous plaît" is extremely natural and sufficient. No verb is required in the shortest form.

### Pronunciation notes

- Celui-ci → /sə.lɥi.si/
- Celle-ci → /sɛl.si/
- Ça → /sa/
- S'il vous plaît → /sil vu plɛ/

Smooth unit: **Celui-ci, s'il vous plaît.**

### Context

Neutral-polite. Safe in shops, restaurants, bakeries, convenience stores. Use while pointing.

## Variations

1. Celui-ci, s'il vous plaît. — this one (masculine)
2. Celle-ci, s'il vous plaît. — this one (feminine)
3. Ça, s'il vous plaît. — this / that (most common neutral form)
4. Celui-là, s'il vous plaît. — that one over there (masculine)
5. Celle-là, s'il vous plaît. — that one over there (feminine)

## Practice summary

Observed, broken down, pronounced, recalled, transformed (celui-ci / celle-ci / ça / celui-là), and used in situation.

## Proof of capability (completed)

User demonstrated:

- Correct recognition and meaning of "Celui-ci, s'il vous plaît."
- Clear understanding of gender and distance differences
- Accurate production without looking
- Correct transformation according to gender/distance
- Appropriate use in a shop/café situation
- Ability to repair a wrong choice using gestures + correct form

## Before

Could not ask for an object in French in a simple, natural way.

## After

Can point to something and say "Celui-ci, s'il vous plaît." / "Celle-ci, s'il vous plaît." / "Ça, s'il vous plaît." Can switch forms according to gender and distance. Can also correct a wrong selection using the same pattern + gestures.
